# Required Assets

Place the following files in this folder before building:

| File | Size | Notes |
|---|---|---|
| icon.png | 1024×1024 | App icon. Use amber (#f59e0b) background with "B" in navy (#0f172a). No rounded corners — Expo adds them. |
| splash.png | 1284×2778 | Splash screen. Navy (#0f172a) background with centered logo. |
| adaptive-icon.png | 1024×1024 | Android adaptive icon foreground. Same as icon but with transparent background. |
| favicon.png | 48×48 | Web favicon. |

## Quick icon generation (requires Node + sharp)
```
npx create-expo-app --template will generate placeholder assets automatically.
```
Or use Expo's online asset generator at https://expo.io/tools.
